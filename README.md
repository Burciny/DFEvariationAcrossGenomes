This repository contains the data and scripts necessary to replicate the final results presented in the paper:

Yıldırım, B. & James, J. E. Gene-level complexity explains genome-wide variation in the distribution of fitness effects. Preprint at https://doi.org/10.64898/2026.04.08.717178 (2026).

The files in the repository are arranged as follows:

GeneBayes_in/ and GeneBayes_out/

Input and output files from the GeneBayes analysis.

Intermediate_data/

Data used for the final analysis and visualization in the scripts under scripts/manuscript/.

scripts/analysis/

Main scripts used for analyses, including creation of intermediate data and calculation of the statistics presented in the paper.
